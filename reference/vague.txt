# Vague Tests - Where Reference Verifiers Disagree
#
# These tests expose differences between metamath.exe and metamath-knife.
# We document the spec-compliant interpretation based on the Metamath book
# (https://us.metamath.org/downloads/metamath.pdf), especially Chapter 4 and
# Appendix B.
#
# Format: VERDICT test_name metamath_result knife_result spec_analysis
#
# VERDICT key:
#   REJECT = should reject (error)
#   ACCEPT = should accept (valid)
#   WARN   = should accept but warn (incomplete proof)

# test15: Multiple $f for same variable in same scope
# Sec. 4.2.5: "There may not be two active $f statements containing the same variable"
# Both f1 and f2 are active simultaneously in global scope -> violates spec
REJECT vague/test15_multiple_f_for_same_variable.mm metamath:ACCEPT knife:REJECT knife_correct

# test16: Conflicting typecodes in nested scopes
# Same rule as test15. When f2 is defined, f1 is still active (outer scope).
# Both $f statements for variable x are simultaneously active -> violates spec
REJECT vague/test16_conflicting_typecodes.mm metamath:ACCEPT knife:REJECT knife_correct

# test19: Illegal character '0' in compressed proof
# Sec. 4.4.5 / Appendix B: compressed proofs use only A-Z (and ? for unknown steps)
# '0' is not a valid compressed proof character -> syntax error
REJECT vague/test19_illegal_characters_in_compressed_proof.mm metamath:REJECT knife:ACCEPT metamath_correct

# test20: Unknown step ? in normal proof
# Sec. 4.4.6: "A proof may contain a ? in place of a label to indicate
# an unknown step. A proof verifier may ignore any proof containing ? but
# should warn the user that the proof is incomplete."
# Verifier MAY ignore but should WARN - this is not a rejection condition
WARN vague/test20_unknown_step_qmark_(should_accept_with_warning).mm metamath:ACCEPT knife:REJECT metamath_correct

# test30: ? in compressed proof
# Sec. 4.4.6 / Appendix B: "Note that partially developed proofs may be saved in
# compressed format if desired. In this case, you will see one or more ?'s
# in the compressed-proof part."
# Explicitly allowed by spec for work-in-progress proofs
WARN vague/test30_qmark_in_compressed_proof.mm metamath:ACCEPT knife:REJECT metamath_correct

# Summary:
# - knife correct on: test15, test16 (multiple $f violations)
# - metamath correct on: test19 (compressed proof syntax), test20, test30 (? allowed with warning)
# - Neither verifier is fully spec-compliant on all 5 tests
